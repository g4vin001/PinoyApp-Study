# AppPinoy Study Edition

This repository publishes the generated AppPinoy study site to GitHub Pages. The 2026 Grades 1–6 curriculum release includes 1,014 lessons across 43 grade and learning-area combinations.

Learner profiles and progress use the current browser. The published bundle includes authored study materials and answer keys for self-study.
